One word a grandma would text about AI. The entry word is:

> **"Witchcraft"**

Warm, a little baffled, and funny in a single word — the way a grandma
would sum up a machine that talks back.

## Run

```sh
node main.ts
```

This writes the entry word to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). The program validates
the word first: 1–30 characters, exactly one word, no whitespace and no
punctuation, then reads the file back to verify it matches.
